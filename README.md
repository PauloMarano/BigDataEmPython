# 📊 Análise de Dados: Big Data com Python & Pandas

Este repositório contém o projeto prático desenvolvido para a disciplina de Big Data. O objetivo foi processar uma base de dados real para extrair indicadores estratégicos.

## 🚀 Tecnologias Utilizadas
* **Linguagem:** Python 3
* **Biblioteca:** Pandas (Manipulação e tratamento de dados)
* **Ferramenta de Versionamento:** Git & GitHub

## 📂 Estrutura do Projeto
Cada um é responsável por gerar uma visão analítica:

1. **`TabelaCalculoFaturamento.py` (Financeiro):** Mapeamento e cálculo do faturamento mensal total acumulado de 3 meses.
2. **`TabelaMediaSatisfacao.py` (Satisfação dos Clientes):** Consolidação da média real de satisfação (CSAT) dos clientes da base de dados.
3. **`TabelaRankingSegmentos.py` (Segmentação de Mercado):** Ranking das categorias e sub-segmentos de mercado com maior volume de projetos ativos.
4. **`TabelaUsoIa.py` (Inovação Clientes):** Levantamento detalhado da taxa de adoção de Inteligência Artificial nos projetos (Ativos vs. Pendentes).
5. **`TabelaSimuladaSatisfacao.py` (Análise Simulada):** Modelo de simulação que prevê o ganho na média geral de satisfação do cliente caso a meta de suporte com cada cliente seja atingida.
6. **`TabelaQuantidadeOverusage.py` (Uso do Sistema):** Contagem de clientes com status de *Overusage* para identificar clientes para upgrade.
